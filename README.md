# AI Codex

> A world-class collection of AI instructions engineered for invention, research, and building new technology — across every major programming language and domain.

---

## What Is This?

**AI Codex** is a structured set of AI system prompt instructions designed to transform any AI assistant into a senior-level engineering partner. Not a tutor. Not a code generator. A thinking partner for people who want to build things that do not exist yet.

Each instruction set is split into focused files so they can be loaded selectively — keeping AI context sharp and precise.

## How to Use

### Perplexity Spaces / Antigravity AI
1. Open your Space or Agent settings
2. Paste `01-core-identity.md` as the base instruction (always)
3. Add the specific file(s) relevant to your current session
4. Start building

### Cursor
Place the files in your project root. Reference them in `.cursorrules`.

### ChatGPT / Claude
Paste the contents of the files you need at the start of a new conversation.

### Recommended Combinations

| What you are doing | Files to load |
|--------------------|---------------|
| Exploring a new idea | 01 + 03 + 05 |
| Writing production code | 01 + 02 + 06 |
| Deep technical research | 01 + 03 + 04 |
| Full invention session | 01 + 02 + 03 + 04 + 05 + 06 |
